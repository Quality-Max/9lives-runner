# Accessibility

9lives provides a command-line runner, a Playwright SDK, and written guides.
We welcome reports about barriers to using these tools or understanding their
output and documentation.

The project has not completed a formal accessibility audit and does not claim
WCAG conformance or screen reader qualification. Accessibility of an application
tested with 9lives also needs to be evaluated separately.

## Report a barrier

Open a [bug report](https://github.com/Quality-Max/9lives-runner/issues/new?template=bug_report.yml)
with the affected command or document, the behavior you expected, and the
barrier you encountered. Include your operating system, terminal or browser,
and assistive technology/version when relevant and comfortable to share.
Suggestions for clearer output, keyboard use, and documentation are welcome.

Public reports should use synthetic examples and omit personal information,
credentials, and private application data. If a report needs personal details,
email [contact@qualitymax.io](mailto:contact@qualitymax.io) instead. Use the
[security policy](SECURITY.md) for security vulnerabilities.
