# Editorial and design brief

This overview is exported from the 9lives homepage with
`scripts/export-overview.cjs`; see [README](README.md). Its source of truth is
`website/app/page.tsx`, not a generated design-app export.

Lead with “Agent fixes. 9l checks the change.” Show the recorded before/after
experiment and three caught request faults. Link all five standalone demo
chapters, marking illustrated versus recorded evidence. Explain reproduce,
review, confirm, and challenge in that order. Start installation with ordinary
Playwright specs; show SDK steps and goals as optional.

Use official QualityMax DM Sans / Space Grotesk fonts, wordmarks, Zinc surfaces,
and Indigo accents. Include light and dark themes with a shared demo preference.
Keep the page responsive and keyboard usable. Bundle fonts and logos locally.

Qualify claims: one synthetic profile application, seven Chromium executions,
saved results. Confirmation and fault testing are experimental. Assertions and
validated reports determine execution results; they do not prove full coverage.
No invented rates, cost claims, benchmarks, or model-authorship guarantees.
