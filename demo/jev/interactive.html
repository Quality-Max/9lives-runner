How does Jev join in?

The shop and browser check work without AI. To ask Jev real questions, the presenter connects a TypeSafe key in the terminal before starting this demo.

read -rs 'TYPESAFE_API_KEY?TypeSafe API key: '
export TYPESAFE_API_KEY
npm run demo:jev -- --live --images
unset TYPESAFE_API_KEY

Each “Ask Jev” click sends this pretend shop’s text and, with images enabled, its screenshot. One request per click. No automatic retries. Up to 6 live requests per session. Your key stays in the local Go process.
