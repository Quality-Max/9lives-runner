    Four little worlds. One big hunt.

    Finish each level to open the next. Cats are the biggest. Dogs are smaller. Mice hide among pantry jars and wedges of cheese. Finally, find one person with a red-and-white striped shirt and hat, round glasses and blue trousers.

    Choose “Race the clock” before starting a level, or take as long as you like. Showing the hiding places is practice: restart that level to unlock the next. Zoom in for the tiniest figures. Keyboard explorers can use Tab, then Enter or Space.

    Your score and timer stay separate from 9lives. The timer pauses while you watch its round. These are original, synthetic illustrations with a known answer map.

    How do Jev and 9lives work together?

    Jev looks at a fresh picture and chooses from nine observed hiding spots. 9lives runs a real Playwright test: it checks the choices, clicks each matching figure, checks every score increase, checks repeat clicks, and checks lookalikes. A broken click produces a failed test receipt.

    You can play and watch 9lives for free. For a live Jev round, connect TypeSafe in a separate terminal, start the demo, then reload. The watch button will use Jev automatically.

    read -rs 'TYPESAFE_API_KEY?TypeSafe API key: '
export TYPESAFE_API_KEY
npm run demo:jev -- --live --images
unset TYPESAFE_API_KEY

    One explicit live run sends one numbered synthetic picture and nine yes/no questions. Your score, the answer map and the broken-click flag stay out of Jev’s input. Uncertain or incorrect choices stop before any click. Up to six live requests per local server session.

    This fixed demo uses the existing 9lives runner. A general Jev goal provider is still planned. Images are experimental; live model accuracy has not been qualified.
