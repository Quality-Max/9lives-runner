# Support

Start with the [README](README.md), [installation guide](docs/install.md),
[CLI reference](docs/cli.md), and [SDK guide](docs/sdk-bridge.md).

Use [GitHub Discussions](https://github.com/Quality-Max/9lives-runner/discussions)
for questions, setup help, and sharing workflows. Community support has no
guaranteed response time.

Use [GitHub Issues](https://github.com/Quality-Max/9lives-runner/issues/new/choose)
for reproducible bugs and concrete feature proposals. Include the CLI/SDK
versions, platform, expected and actual behavior, and a minimal example with
synthetic data. See [CONTRIBUTING.md](CONTRIBUTING.md) to contribute a fix.

Public issues and discussions are visible to everyone. Omit credentials,
private application data, page content, and raw receipts or logs. Use the
[security policy](SECURITY.md) for private vulnerability reports and the
[code of conduct](CODE_OF_CONDUCT.md) to report community conduct concerns.
See the [accessibility statement](ACCESSIBILITY.md) for accessibility feedback.
